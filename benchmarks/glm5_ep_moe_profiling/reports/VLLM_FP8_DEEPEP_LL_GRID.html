The fix that unblocked this. The vllm-openai image ships DeepEP 73b6ea4 (allow_mnnvl, no use_fabric) which fails cross-node at deep_ep.cpp:226 'invalid resource handle'. sglang works because it builds DeepEP's hybrid-ep branch with Buffer(use_fabric=True) → CU_MEM_HANDLE_TYPE_FABRIC shareable handles. Fix (no image rebuild): built hybrid-ep DeepEP d28bd67 into a /home overlay (only deep_ep_cpp; CUDA dev headers via pip), patched vLLM all2all.py to pass use_fabric=True under VLLM_DEEPEP_USE_FABRIC=1, bind-mounted both into the container. Verified: 8-rank cross-node Buffer SUCCESS, then this full EP8–64 grid.
